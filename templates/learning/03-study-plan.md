# Weekly Review

At the end of each week, answer the following questions:

* What did I learn?
* What was more difficult than expected?
* Which topics still need review?
* Which topics can be applied immediately?
* What should change next week?

Update the backlog and the following week's plan accordingly.

---

# Planning Principles

* Plan one week at a time.
* Limit new topics to a manageable number.
* Schedule reviews before adding more content.
* Balance reading, implementation, and review.
* Leave buffer time for difficult topics.
* Update the plan as your understanding evolves.

A study plan is a living document that should be refined throughout the learning journey rather than treated as a fixed schedule.
